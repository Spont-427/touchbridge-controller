FIRST-TIME PAIRING

Connect a computer

Select a nearby PC, then enter the six-digit PIN shown in its TouchBridge terminal. You only need to do this once per phone.

The PIN is only needed the first time. Your trusted device token is stored securely on Android.

Connections use your local network. The current HTTP transport is unencrypted; use trusted private Wi-Fi and never expose the server to the public internet.
